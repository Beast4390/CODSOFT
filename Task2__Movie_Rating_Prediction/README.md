# Movie Rating Prediction with Python

## Objective
Predict movie ratings using machine learning techniques based on movie features such as genre, director, and actors.

## Dataset
IMDb Movies India Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Machine Learning Model
Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- R² Score

## Results
MAE: 1.06
R² Score: 0.08

## Conclusion
Built a machine learning model capable of predicting movie ratings using historical movie data.
