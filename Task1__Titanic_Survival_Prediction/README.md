# Task 1 - Titanic Survival Prediction

## Objective
Predict whether a passenger survived the Titanic disaster using Machine Learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest

## Results
- Random Forest Accuracy: 82.12%
- ROC-AUC Score: 0.90
