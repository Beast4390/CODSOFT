# Iris Flower Classification

## Objective
Classify Iris flowers into different species using Machine Learning.

## Dataset
Iris Dataset containing:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Algorithm
Random Forest Classifier

## Results
- Accuracy: 100%
- Successfully classified Iris flowers into:
  - Iris-setosa
  - Iris-versicolor
  - Iris-virginica
